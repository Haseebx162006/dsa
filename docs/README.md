# Documentation

## Project Overview
This is a Java-based Data Structures and Algorithms (DSA) project. It contains lab questions and exercises focused on core programming concepts including object-oriented programming, exception handling, and data structures.

## Project Structure
```
├── .idea/          # IntelliJ IDEA configuration files
├── LabQuestion/    # Lab exercises and solutions
│   ├── cow.java    # Cow class implementation
│   ├── Exception.java # Custom exception handling
│   └── *.class     # Compiled Java classes
├── src/            # Main source code directory
├── DSA.iml         # IntelliJ IDEA module file
└── .gitignore      # Git ignore rules
```

## Lab Questions
The `LabQuestion` directory contains various programming exercises:
- **cow.java**: Implementation of a Cow class demonstrating OOP principles
- **Exception.java**: Custom exception handling examples

## Prerequisites
- Java Development Kit (JDK) 8 or higher
- IntelliJ IDEA (recommended) or any Java IDE

## Building and Running
1. Open the project in IntelliJ IDEA
2. Ensure JDK is configured in project settings
3. Compile and run individual Java files:
   ```bash
   javac LabQuestion/cow.java
   java LabQuestion.cow
   ```

## Development
- Use IntelliJ IDEA for an optimal development experience
- Follow Java naming conventions
- Write unit tests for your implementations
